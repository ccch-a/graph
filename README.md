# Эпюр

Учебный веб-сервис для построения ортогональных видов, разрезов, сечений, аксонометрии и развёрток. Работает полностью в браузере, без сервера, сборки и регистрации.

## Запуск локально

Откройте `index.html` или запустите локальный сервер в этой папке:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в его корень **содержимое папки `epur-site`**: `index.html`, `style.css`, `app.js`, `geometry.js`, остальные файлы.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Укажите ветку `main`, папку `/ (root)` и нажмите **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Если страница сначала выдаёт 404, подождите завершения публикации на вкладке **Actions** и обновите страницу.

## Импорт варианта

Кнопка **«Импорт варианта»** принимает JSON и CSV. Готовый пример — `пример-варианта.json`. Текущий проект можно сохранить через **Экспорт → Файл варианта**.

Данные и чертежи пользователя не отправляются на сервер. Автосохранение выполняется в локальном хранилище браузера.
