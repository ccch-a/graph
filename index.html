    Новый чертёж

    Импорт варианта

    Загрузите параметрическое тело или собственную 3D-модель. Данные обрабатываются только в вашем браузере.

    Формат JSON
    {
  "variant": "12",
  "name": "Призма шестигранная",
  "shape": "prism",
  "params": { "radius": 40, "height": 60, "sides": 6 },
  "section": { "axis": "y", "offset": 0 },
  "student": "", "group": ""
}
    Как импортировать собственную модель?

    В JSON укажите "shape":"mesh", массив vertices с координатами [x, y, z] и массив faces с индексами вершин. CSV принимает строки имя,x,y,z и создаёт каркас.
